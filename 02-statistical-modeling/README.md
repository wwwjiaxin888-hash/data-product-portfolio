# 数字技能对家庭金融决策的影响机制

**全国大学生统计建模大赛 · 省赛三等奖** · Stata / Python / XGBoost / SHAP

## 我的分工

负责部分数据清洗、描述性统计和论文撰写。以下数据合并、建模和结论均为团队成果。

## 如何分析

1. 根据个人与家庭 ID 关联 CFPS 2022 的家庭成员关系、家庭经济及个人三个子库，形成 **8,716 个有效样本**。将数字接入、使用、创造三个维度下的 **5 项行为指标**标准化并合成数字技能指数。
2. 用 Probit 和 Tobit 分析参与概率和配置比例，再用 XGBoost 对保险购买和风险市场参与建模。风险参与正样本仅占 **11.29%**，采用分层划分和类别加权。调参使用交叉验证，最终报告测试集结果。
3. 用 SHAP 检查非线性和年龄差异，并把结果转为分龄服务建议，例如对 **60 岁及以上**人群保留线下服务渠道。
