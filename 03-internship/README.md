# 企业数据月度统计交付

**产品实习** · 指标口径 / Python / 数据质量

客户需要按月比较不同地区、不同企业类别的指标。我参与梳理统计维度和指标口径，与同事协作交付月度明细及汇总。

| 问题 | 分析与处理 |
| --- | --- |
| 各批次能否比较 | 按统计期、地区和企业类别对齐指标，核对名单版本和取数时间。 |
| 全量统计导出受阻 | 采用 MapReduce 思想逐行读入 JSON。块内按维度分组计算部分和与计数，再按相同主键累加中间结果，减少一次性读入的数据量。 |
| 汇总如何验收 | 按统计日期和区域对齐汇总，核对差异及单位，结合两期明细追查变动。 |

项目贡献是采用分块方案、核对结果和协作交付。案例仅展示业务思路与通用方法。
