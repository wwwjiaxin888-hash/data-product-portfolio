# 林业社会化服务对农户增收的影响路径

**省级大学生创新创业训练计划 · 已结题**

我参与原始数据预处理、市场服务模块的前期文献梳理与计量方案筹备，以及调研人员培训方案设计。信贷实证为团队成果，我以第二作者发表相关期刊论文。

团队基于贵州 **1,048 户**有效样本，分析正规信贷如何通过生产性资本投入与林地经营规模影响林业经营收入。高收入组的正规信贷增收效应显著，低、中收入组效应在样本中不显著。项目完成了信贷子方向的实证，其他服务模块完成了前期梳理。
